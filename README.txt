おつり計算トレーニング
======================

暗算・おつり計算を練習するための、個人制作Webアプリです。表示された商品価格を1,000円から引き、おつりを入力して練習します。

■ 機能
・10問、25問、50問、100問から問題数を選べます。
・時間制限なしで、チャレンジにかかったタイムを測定します。
・正解数、正答率、平均回答時間を確認できます。
・過去の成績、問題数別の自己ベスト、タイム推移グラフを表示します。
・Enterキーで回答でき、成績を削除することもできます。

■ 起動方法
index.html をWebブラウザで開いてください。ダブルクリックでも起動します。GitHub Pagesにもそのまま配置して公開できます。HTML、CSS、JavaScriptだけで動作し、外部サーバーやバックエンドは必要ありません。

■ 成績とプライバシー
成績は利用中のブラウザのlocalStorageに保存され、サーバーへ送信されません。別のブラウザや端末とは成績が共有されません。ブラウザの保存データを消去すると成績も消えることがあります。画面の「成績を見る」から「成績データを削除」を選ぶと、確認後にこのアプリの成績を消去できます。

以前のバージョンで保存した成績は初回読み込み時に新しい保存先へ移行します。問題数の情報がない過去記録は50問として扱います。
